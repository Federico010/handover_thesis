# Human–Robot Handover — M.Sc. Thesis

ROS 2 framework for dynamic object handovers on Franka Research 3, developed for my M.Sc. thesis with Thales Alenia Space.

## Technical focus

- RGB-D hand tracking, Kalman-based state estimation, and short-horizon motion prediction
- Adaptive handover targets, collision avoidance, and force-based admittance control
- Integration and testing on a physical Franka Research 3

The implementation is available in the [`tesi_federico_urbini` branch](https://github.com/MattiaCastelmare/franka_ros2/tree/tesi_federico_urbini) of a collaborative Franka ROS 2 repository.
